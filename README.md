# tad-tracker-media

Public images for [@TADTracker](https://x.com/TADTracker) posts (https://tad-tracker.eu).

- Images live in `social/YYYY-MM-DD/<name>.png` and are referenced by Buffer via
  `https://raw.githubusercontent.com/dakurt/tad-tracker-media/main/social/...`.
- Uploaded automatically by `scripts/buffer_post.py --image-file` in the (private) site repo.
- Images only. No secrets, no source code, no personal data.
